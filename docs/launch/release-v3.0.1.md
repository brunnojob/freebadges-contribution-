Freebadges Contribution is now a public PT-BR / English browser dashboard for GitHub achievement workflows and explicitly labeled contribution history.

### Included

- Four workflows: Quickdraw, Pull Shark, Pair Extraordinaire and YOLO.
- Seven achievement guides and Starstruck milestone estimates.
- Execution from the browser or a private GitHub Actions executor in the connected user's account.
- Encrypted Actions secrets, operation evidence, cancellation and credential removal.
- Contribution-calendar preview and labeled synthetic-history generation.
- Actual product screenshot, a sharing image, contribution guidance and issue templates.

### Authentication fix

Native browser fetch is now invoked without an incorrect receiver. Network, timeout and malformed-response errors are distinguished, and versioned browser modules refresh cached authentication code.

### Validation

30 Node tests and the existing repository checks pass. Browser QA exercised the interface and a simulated two-account execution. Tests do not verify real badge awards. GitHub controls achievement eligibility and processing.
