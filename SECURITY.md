# Security

Do not include access tokens, repository secrets or private account data in public issues, screenshots or logs.

If a token may have been exposed, revoke it in GitHub Settings → Developer settings → Personal access tokens. Removing a browser session does not revoke a token or delete secrets saved in a private Actions executor.

Use GitHub's private vulnerability reporting option in the repository Security tab if available. If private reporting is unavailable, contact the maintainer at contato@brunnodev.store with a short description and sanitized reproduction steps. Do not send a live token.

This project does not verify achievement awards and must not bypass repository protections or send visitor credentials to the public site repository.
