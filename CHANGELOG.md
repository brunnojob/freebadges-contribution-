- Seven achievement guides, Starstruck milestone estimates and contribution-history planning.

- Add an actual interface screenshot, a social-preview asset, contribution guidance and issue templates.

The existing Python/Ruby history auditors and original Free Contributions CLI are preserved. Real badge issuance has not been validated by automated tests.
